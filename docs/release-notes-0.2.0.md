# SnapAsk 0.2.0

本版本重构了截图后的完整交互与视觉系统，同时保留原有的隐私和快照一致性边界。

## 新交互

- 框选完成后直接显示 Snipaste 式玻璃浮动工具条，可进入矩形、箭头、文字、马赛克、复制、保存、贴图或 AI 提问。
- 编辑器贴合截图选区出现，改为紧凑的纯图标工具条，不再自动弹出 AI 回答卡。
- AI 回答卡移除服务、模型、目标域名、继续提问和两类重试控件；服务与模型仅在设置中选择。
- 回答文字被选中时，回答框右上角显示复制按钮，并只复制选中的内容。

## Glassmorphism

- 截图工具条、编辑器、回答卡、设置页、AI 服务向导及其他应用窗口共用统一的半透明材质、圆角、细描边和控件状态。
- Windows 11 优先使用系统 Mica/Transient 背板；Windows 10、远程会话、高对比度或系统合成不可用时自动降级为高可读背景。
- 设置页改为“通用 / AI 服务 / 隐私与关于”侧边栏布局。

## 性能与可靠性

- 回答卡未显示时不再参与编辑器拖动联动；显示后将高频窗口移动合并到短帧间隔，减少重复布局和双窗口重绘。
- 透明窗口恢复系统背景清理，修复毛玻璃页面切换和流式内容更新时的像素残影。
- 单实例先确认再异步打开设置，修复连续双击时偶发的“无法启动”误报。
- 应用版本统一更新为 0.2.0，构建、设置页、便携包和 Release 标签共用同一版本来源。
- 保存、复制、贴图和 AI 发送继续共用唯一的不可变快照渲染结果。
- 未明确发送前不会上传截图；API Key 仍仅保存在 Windows Credential Manager，不进入普通配置、导出文件或日志。
