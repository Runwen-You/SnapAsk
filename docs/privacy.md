# SnapAsk 隐私与安全边界

截图、标注、问题和回答默认只存在于当前进程内存。SnapAsk 不自动建立会话历史，也不把截图写入临时目录；只有用户主动使用“保存”才会写出 PNG。

只有用户在回答卡明确点击“发送”或按 `Ctrl+Enter` 后，当前标注状态才会经唯一的 `SnapshotRenderer` 管线扁平化为 PNG，并发送给卡片中显示的服务域名。修改标注不会自动发送；重试原快照复用原 PNG，使用当前截图重试则要求再次明确点击。模型列表与连接测试不能接收当前截图、问题或任意用户载荷；图片能力测试只用程序内置的固定测试图。

API Key 只通过 Windows Credential Manager 的 `CredWriteW`、`CredReadW` 和 `CredDeleteW` 管理。普通 `providers.json`、QSettings、配置导出、错误消息和日志只允许保存不敏感的档案字段及凭据引用，不得包含 Key。删除服务档案时用户可以同步删除系统凭据，复制档案不会复制凭据。

OpenAI 官方端点可直接使用；任何自定义端点在首次网络请求前都会显示规范化 origin，并要求单独授权。非 localhost 公网端点必须使用 HTTPS，TLS 校验不能关闭，重定向只允许同源。连接授权发生在读取凭据和建立连接之前。

所有 Qt 日志经过 `RedactingLogger`，会清除授权值、Key、令牌、密码、长编码载荷、图片 data URL，以及标记的问题、回答和请求体。程序默认不创建日志文件。代码仍遵守数据最小化：不得主动记录请求体、剪贴板内容、问题、完整回答、图片字节或凭据。

回答 Markdown 不执行 HTML 或脚本，不自动加载远程图片和其它资源；打开 HTTP/HTTPS 外部链接前必须确认。软件不向模型提供电脑控制工具。

像素化马赛克会在上传 PNG 中栅格化，但不应被视为强安全脱敏。首启说明会明确这一限制；拒绝说明会直接退出，不启动截图或 AI 服务。
